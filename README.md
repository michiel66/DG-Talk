# DG-Talk

DG-Talk is een aangepaste Android TeamSpeak 3-client, gebaseerd op [NotMurPh/TeamSpeak-Android-TS3](https://github.com/NotMurPh/TeamSpeak-Android-TS3), release `build-25` (`dafbab92037b3ae135e494319dd4016fdcb1f2b9`).

**Beoogde wijzigingen:** appnaam **DG-Talk**, eigen launcher-icoon en standaardserver `heerlen.mijnts3.nl`. De oorspronkelijke audio-, PTT- en interfacefuncties blijven intact.

Het originele project valt onder de MIT-licentie, met aanvullende licentieverklaringen voor componenten van derden. Zie de originele [LICENSE](https://github.com/NotMurPh/TeamSpeak-Android-TS3/blob/build-25/LICENSE) en [THIRD_PARTY.md](https://github.com/NotMurPh/TeamSpeak-Android-TS3/blob/build-25/THIRD_PARTY.md).
